# Resultados

Esta pasta guarda as tabelas agregadas, figuras e resumos que documentam os
experimentos. O arquivo de entrada para comparações gerais é
`metodos_final.csv`.

Arquivos por imagem, embeddings, features, coortes de trabalho e caches são
reconstituíveis e deliberadamente ignorados pelo Git. Os scripts que produzem
estes artefatos ficam em `../experiments/`.

`../paper` é um atalho de compatibilidade para esta pasta. Não adicionar novos
arquivos por aquele caminho; use `results/` explicitamente.
